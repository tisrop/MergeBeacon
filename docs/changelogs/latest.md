# 更新日志

这里记录每个版本最值得关注的体验变化，不逐条翻译提交记录，也不要求与 Release Notes
一一对应。如果你只想知道“升级后哪里更好用了”，看这里就够了。

## v0.9.0（2026-07-25）

这一版主要打磨日常评审体验：界面更清爽，找代码和翻列表也更快。

### 更舒服的界面

- 重新整理了主要页面的颜色、间距、层级和交互状态。信息很多时更容易分清重点，长时间评审也
  不那么累。
- 统一了表单、卡片、侧栏和弹出内容的视觉细节，页面之间切换时更连贯。
- 调整了 AI 评审筛选等容易拥挤的控件，小窗口下也能更完整地看到选项。

### 在 Diff 里直接找代码

- 查看文本 Diff 时，可以使用 `⌘/Ctrl + F` 搜索当前文件。
- 支持区分大小写、全词匹配和正则表达式，并能快速跳到上一个或下一个结果。
- 搜索只影响当前文件，不会打断正在进行的评论和评审。

### 翻页不再只能一步一步来

- PR / MR 列表现在可以直接跳到指定页。
- 可以按需要选择每页显示 10、20、50 或 100 条记录。
- 修复了结果数量重复显示等小问题，列表信息更干净。

### 更稳定的图片预览

- 修复了图片第一次打开时偶尔不显示或显示旧内容的问题。
- 快速切换文件时，较早返回的图片不会再覆盖当前正在查看的文件。

## v0.8.0（2026-07-24）

这一版让大型 PR / MR、图片变更和问题排查都更从容。

### 图片变更可以直接看

- 支持在 Diff 中预览常见图片的变更前后内容，不必下载后再手动比较。
- 图片过大、格式无效或平台无法提供内容时，会明确说明原因，不会留下空白区域让人猜测。
- 修复了 Fork 和跨仓库 PR / MR 获取图片源文件不准确的问题。

### 大型改动也有清楚的边界

- 创建 PR / MR 前会尽可能完整地加载 Commit 和 Diff，并在平台只返回部分结果时明确提示。
- 即使预览不完整，也不会错误阻止一个本来可以正常创建的 PR / MR。
- Closed 和 Merged 列表支持继续分页浏览，不再只看到第一页。

### 找仓库、选参与者更省事

- 侧栏新增仓库搜索，仓库较多时不用反复滚动查找。
- Reviewers、Assignees、标签等候选项支持搜索；加载失败后可以直接重试。
- 设置入口和侧栏状态进一步统一，加载过程中不再显示容易误点的“加载更多”。

### 更新与问题排查更可靠

- 自动更新支持跟随系统代理，企业网络和代理环境下更容易正常检查及下载更新。
- 错误提示带有可用于定位问题的请求编号，并会在本地保留经过脱敏的错误日志。
- 日志不会记录 Token、API Key、仓库代码或完整的私有服务地址。

## v0.7.0（2026-07-20）

这一版补上了跨平台创建 PR / MR 的完整入口，也让 AI 评审结果更容易继续使用。

### 在应用里创建 PR / MR

- GitHub、GitLab 和 Gitee 都可以直接创建 PR / MR。
- 可以选择目标仓库、Fork 源仓库、源分支和目标分支，并按平台能力添加参与者与标签。
- 创建前可以编辑和预览 Markdown 描述，查看 Commit 列表、完整 Diff，或只看某个 Commit 的改动。
- 如果参与者或标签只有部分写入成功，应用会保留已经创建的 PR / MR，并告诉你哪些内容需要补充。

### AI 评审可以接着上次继续

- 评审结果按仓库、PR / MR 和提交版本保存在本地，重新打开后仍能找到。
- 历史记录会说明使用的模型、评审范围、关注方向和提交版本，方便判断结果是否仍然适用。
- AI 建议和人工评论使用统一草稿；真正提交前仍由你检查和确认。
- PR / MR 出现新提交后，旧结果和旧草稿会被标记为过期，避免把评论发到已经变化的代码上。

### 键盘操作更顺手

- 下拉选项支持使用方向键循环浏览。
- 搜索、输入法输入、焦点和选中状态更加一致。
